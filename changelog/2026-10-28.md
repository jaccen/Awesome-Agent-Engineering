## Auto-Update Pipeline

- **Daily arXiv scan** — 8 query families covering the full Agent landscape; GitHub Actions runs at UTC 06:00 daily
- **Weekly GitHub Trending** — 7 agent-related queries (stars > 50); runs Monday UTC 06:00
- **Weekly HuggingFace Trending** — agent/tool-use/VLA/RAG models sorted by weekly likes
- **Knowledge base validation CI** — validates all 5 JSON files on every push/PR to `data/`

## Evidence Protocol (A1–A5)

Every entry follows verification rules:
- **A1**: Method name self-stated in title/abstract or repo README
- **A2**: arXiv ID (if any) verified reachable
- **A3**: GitHub/code URL (if any) live
- **A4**: Venue from official metadata
- **A5**: Description is a one-line technical summary, no hype

## Design Decisions

- **Project name**: Awesome-Agent-Engineering — covers the full Agent engineering stack
- **Scope**: Full-stack Agent (LLM Agent + Multi-agent + Embodied + World Model + Web/GUI + Code)
- **Seed scale**: Lean start (518 entries), grow via auto-update
- **Update frequency**: Daily academic + weekly industry
