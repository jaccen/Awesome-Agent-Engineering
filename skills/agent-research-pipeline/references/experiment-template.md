# Agent 论文实验模板

> 用途：`agent-research-pipeline` skill 阶段5/6 的可填充模板。复制本文件到论文工作目录，按表格逐项填写。
> 配套：流程说明见 `SKILL.md`「阶段5·实验设计」与「阶段6·数据分析」；基准清单见 `data/benchmarks.json`。
> 纪律：每条贡献须有对应实验；机制归因类声称须补负对照；多种子统计（≥3 seeds）+ 配对 t 检验；诚实报告 negative results；先关键场景达标再全量重跑。

## 9. 实验自检清单（投稿前）

- [ ] 每条贡献有对应实验验证（见第1节）
- [ ] 主实验 ≥3 benchmark、≥5 基线
- [ ] 消融完备（每个组件都有去除实验，见第3节）
- [ ] 机制归因声称有负对照
- [ ] ≥3 seeds，报告均值±标准差
- [ ] 配对 t 检验或 Wilcoxon 检验，给出 p 值
- [ ] Negative results 如实报告（见第7节）
- [ ] 关键场景先达标再全量（见第8节）
- [ ] 主表数值小数位与基线一致，最优加粗
- [ ] 实验日志可复现（run_id + 超参 + 日志路径，见第4节）
- [ ] 效率实验报告 FPS/内存/Token（如声称高效）
- [ ] 定性图选样无偏（不挑最好 case）
